# Aura In Cyprus

Türkçe Kuzey Kıbrıs gayrimenkul sitesi. Proje, mevcut Piller HTML şablonunun yapısını koruyarak Aura In Cyprus markasına uyarlanmıştır.

## Çalıştırma

PHP kurulu bir ortamda proje kök dizininde php -S 127.0.0.1:8000 komutunu çalıştırın. Ardından http://127.0.0.1:8000 adresini açın. Statik sayfalar tarayıcıda görüntülenebilir. İletişim formunun e-posta göndermesi için sunucuda geçerli bir AURA_CONTACT_EMAIL ortam değişkeni ve PHP mail() yapılandırması gerekir.

## Ana sayfalar

- index.html — ana sayfa
- property.html — gayrimenkul ilanları
- property-details.html — ilan detayı
- contact.html — iletişim formu

## Marka katmanı

Aura’ya özel stiller ve etkileşimler assets/css/aura-theme.css ile assets/js/aura-*.js dosyalarında bulunur. Özgün şablon bileşenleri korunmuştur.
